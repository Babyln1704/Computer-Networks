SECURE FILE CONVERSION SYSTEM

Authors: Baby L N, Shailaja P C, Nandhana S
Department: CS(AI ML)
University: PES University, Bengaluru
Subject: Computer Networks

---

OVERVIEW
This project is a Secure File Conversion System developed using Python. It allows users to upload files, convert them into different formats, and download them securely using TCP sockets and SSL encryption.

---

FEATURES

- Secure communication using SSL
- Multiple file conversion support
- GUI-based client using Tkinter
- Multi-client handling using multithreading
- Efficient processing using SJF scheduling (Priority Queue)

---

SUPPORTED FORMATS

- TXT → PDF, DOCX, CSV
- DOCX → TXT, PDF, CSV
- PDF → TXT, DOCX, CSV
- CSV → TXT, PDF
- PNG/JPG → JPG/PNG

---

WORKING
Client sends file securely using SSL → Server processes using SJF scheduling → File is converted → Result is sent back to client.

---

CONCLUSION
This project demonstrates secure communication, efficient scheduling, and multi-format file conversion with a user-friendly interface.
